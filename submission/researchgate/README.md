# HATI-Madrid ResearchGate release package

Version 1.0 release candidate, prepared 2026-09-11.

This bounded package prepares the existing HATI-Madrid study for a human ResearchGate
upload as a **non-peer-reviewed preprint / research work**. It does not upload anything,
select a journal, or change scientific outputs, thresholds, scenarios, evidence classes,
uncertainty classes, or headline values.

## Package contents

- `PUBLIC_TRUTH_AUDIT.md` - repository truth audit with MATCH / STALE / CONTRADICTION / UNKNOWN.
- `RESEARCHGATE_METADATA.md` - exact upload metadata, availability and limitations text, and citation.
- `FIGURE_INVENTORY.md` - release figure files and captions.
- `build_researchgate_pdf.py` - reproducible PDF builder using the canonical public manuscript.
- `qa_researchgate_release.py` - release assertions against canonical tables and files.
- `HATI_Madrid_ResearchGate_Preprint_v1.0.pdf` - upload candidate generated by the builder.

## Canonical source and bounded transformations

The public canonical manuscript source is `../../manuscript/MANUSCRIPT_TMP_v0.2.md`.
The PDF builder uses that file without changing its scientific body, results, thresholds,
scenario definitions, references, or captions. It makes only release-administration changes:

1. removes the stale journal-target line and unresolved affiliation/contact/ORCID placeholders;
2. uses the author name independently supported by repository Git history, `Soroush Karahrodi`;
3. labels the document as a non-peer-reviewed ResearchGate release candidate;
4. replaces unresolved declaration placeholders with a factual publication-status and public
   data/code availability block; and
5. embeds the four locked publication figures after the manuscript text.

Affiliation and ORCID are not stated because the repository does not verify them. The owner
should add them in ResearchGate only if factually correct.

## Rebuild

From the repository root, using Python with ReportLab and pypdf installed:

```powershell
python submission/researchgate/build_researchgate_pdf.py
python submission/researchgate/qa_researchgate_release.py
```

The builder writes only the PDF in this folder. ResearchGate upload remains a human action.
