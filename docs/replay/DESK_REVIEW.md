# Desk-review protocol — not yet executed

Purpose: falsify whether linking recorded scenario eligibility to the map adds
useful scientific inspection beyond the candidate list. This is an interface
review, not a tourism behavior study or physical field validation.

Record reviewer/date, browser/viewport, commit, prior familiarity and whether
assistance was required. Do not publish performance claims from this small
qualitative review. No findings are asserted in this protocol.

## Tasks and answer key

1. Select S1. Identify the survivor set and point to one survivor and one
   exclusion on the map. Expected: 9 survivors, 17 excluded; survivors
   A01,A03,A04,A10,A12,A14,A17,A18,A21. Source A16 is separate.
2. Select S8. Explain what zero survivors means. Expected: 26 evaluated;
   0 survivors; first-failure groups 15 accessibility, 6 hotter outdoor,
   5 closed. The 26 assets are not all within 500 m. The conclusion is
   contingent on this scenario's fixed reach and source/time.
3. In S4 select A24. Identify its recorded first failure and locate its pinned
   source row without opening a raw CSV. Expected: EXCLUDED,
   INSUFFICIENT_EVIDENCE, UNSTABLE decision confidence, LOW evidence confidence;
   `phase3_scenarios.csv`, key `(S4,A24)`, plus the asset-time record.
4. Select S7. Explain why A24 is now SRC instead of OUT. Expected: it is the
   source, not a candidate evaluated against itself. Its uncertainty remains.
5. Find a surviving outdoor candidate. Explain why IN does not mean low heat,
   safety or robust confidence. Use the distinct labelled fields as evidence.
6. Change to 12:00. Explain the resulting state. Expected: asset inspection
   remains available, no scenario is fabricated and no stale back link remains.
7. Repeat candidate/provenance selection using only the keyboard. Repeat a
   key task at a narrow viewport. Record any inaccessible fact or lost focus.

## Does the map help?

Ask the reviewer to answer one spatial question using the map and the same
question using only the list: where are the source, survivors and exclusions
relative to each other? Alternate which is used first across reviewers when
possible. Record a concrete observation, confusion or inability to answer;
do not infer route availability or neighborhood-wide thermal conditions.

For each task record: completed independently / with assistance / not completed;
what evidence was used; any thermal-versus-eligibility or confidence-versus-safety
confusion; and any map-specific contribution beyond the list.

## Decision after review

Continue only if the reviewer can identify membership, distinguish it spatially,
explain a recorded exclusion, separate thermal state/confidence/eligibility,
and locate provenance. Repair blocking accessibility or state problems first.

Stop spatial expansion if the map adds no concrete inspection value, or if it
repeatedly causes users to read thermal condition as eligibility or confidence
as safety. A technically passing build alone does not establish usefulness.

Reviewer observations and the usefulness verdict are deliberately blank until
an actual review takes place. No field observations or simulated participants.
